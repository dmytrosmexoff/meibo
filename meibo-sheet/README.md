# 利用者名簿 на Umbrel + MySQL

Внутри: сайт (`web/index.html`), серверная часть на PHP (`web/api.php`), MySQL 8.4 в отдельном контейнере.
Вход в приложение защищает сам Umbrel (его пароль), отдельных логинов нет. Одновременно работать могут несколько устройств: изменения общие и подтягиваются сами примерно раз в 20 секунд.

## Что понадобится
- Умеете открыть терминал Umbrel (Настройки → Дополнительно → Терминал) или зайти по `ssh umbrel@umbrel.local`.
- Один раз выход в интернет **во время установки** (скачать образы `php:8.3-apache` и `mysql:8.4` и добавить магазин приложений из Git). После этого сервер может работать без интернета.

## Шаг 0. Проверка без Umbrel (рекомендую сделать первым)
На любом компьютере с Docker, в папке `meibo-sheet`:
```
docker compose -f docker-compose.standalone.yml up -d --build
```
Откройте `http://АДРЕС:1475/check.php`. Должно быть написано `ALL GOOD`. Сайт открывается по `http://АДРЕС:1475/`.
В этом режиме входа нет, используйте только в закрытой сети. Остановить: `docker compose -f docker-compose.standalone.yml down`.

## Шаг 1. Собрать образ сайта на сервере Umbrel
Скопируйте папку `umbrel-meibo-store` на сервер (scp или USB), затем:
```
cd umbrel-meibo-store/meibo-sheet
docker build -t meibo-web:1.0 .
docker pull mysql:8.4
```
Если у сервера совсем нет интернета, на другом компьютере выполните то же и сохраните образы:
```
docker save meibo-web:1.0 -o meibo-web.tar
docker save mysql:8.4 -o mysql.tar
```
Перенесите `.tar` на сервер и загрузите: `docker load -i meibo-web.tar && docker load -i mysql.tar`.

## Шаг 2. Добавить приложение в Umbrel
Umbrel устанавливает приложения из Git-репозитория («магазин сообщества»):
1. Загрузите папку `umbrel-meibo-store` в репозиторий (корень репозитория = эта папка, внутри `umbrel-app-store.yml`).
2. В Umbrel: App Store → меню «⋯» → Community App Stores → добавьте адрес репозитория.
3. Найдите приложение «利用者名簿» и нажмите «Установить». Открывается по порту 1475 через Umbrel.

## Шаг 3. Проверка
Откройте `http://umbrel.local:1475/check.php` (будет запрошен вход Umbrel). Ожидается `ALL GOOD` и версия MySQL.
Если там `ERROR`, скопируйте строку целиком: по ней видно причину (чаще всего MySQL ещё запускается, подождите минуту и обновите страницу).

## Резервная копия
Раз в сутки (например, через cron на сервере):
```
docker exec meibo-sheet_db_1 sh -c 'mysqldump -umeibo -p"$MYSQL_PASSWORD" meibo' > /путь/к/диску/meibo-$(date +%F).sql
```
Хранить на отдельном диске и раз в месяц проверять, что копия восстанавливается:
`docker exec -i meibo-sheet_db_1 sh -c 'mysql -umeibo -p"$MYSQL_PASSWORD" meibo' < meibo-ДАТА.sql`
Данные базы лежат в `~/umbrel/app-data/meibo-sheet/data/mysql`. При удалении приложения из Umbrel они могут пропасть: сначала сделайте копию.

## Таблицы
`people` (человек и все версии его настроек), `days` (лист за дату и его цифра 1→4), `attendance` (кто пришёл и кто ночевал, удобно для SQL-отчётов), `staff` (список сотрудников), `log` (журнал изменений), `meta` (счётчик листов).
Пример отчёта: в `schema.sql` внизу.

## Как это работает
- Изменения отправляются на сервер через 0.4 с после правки. Если связь пропала, наверху появляется жёлтая надпись, а правки отправятся сами, когда связь вернётся.
- Если два человека одновременно правят одно и то же, побеждает тот, кто сохранил первым, второй получает сообщение и свежие данные.
- Цифру листа (1, 2, 3, 4, 1…) выдаёт сервер одной операцией при первом сохранении дня, поэтому два устройства не получат одинаковую.
- Старые данные из браузерной версии сюда автоматически не переносятся (список людей придётся ввести заново).
