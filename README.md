# Meibo — магазин Umbrel

В магазине два приложения:
- **meibo-sheet** (версия 1.9.13) — лист 利用者名簿 и его администрирование.
- **meibo-crm** (версия 0.4.0) — вход работников, их записи дня, печать листа в дизайне meibo. Язык: русский на русском устройстве, японский в остальных случаях.

Перед установкой замените токен `CHANGE-ME-READ-TOKEN`:
- в `meibo-sheet/docker-compose.yml` — `READ_TOKEN`;
- в `meibo-crm/docker-compose.yml` — `MEIBO_TOKEN` (то же значение) и `MEIBO_URL` (адрес вашего Umbrel, например `http://192.168.1.10:1475`).
